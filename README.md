
# MathEMazing

## About the Project
MathEMazing is an educational game project where the player explores different places to obtain the artifacts needed to unlock a story hidden within those items. It is a game that utilizes mathematics as a main component and a learning tool, incorporating mathematical challenges and problem-solving activities into its gameplay. Through exploration, puzzles, and interactive encounters, players are encouraged to apply their mathematical knowledge while progressing through the story. The game aims to make learning mathematics more enjoyable, engaging, and interactive by combining education with adventure.

## Game Features
- **Exploration:** Explore different locations and discover hidden artifacts.
- **Mathematical Challenges:** Solve math problems to overcome obstacles and progress.
- **Artifact Collection:** Collect special artifacts that reveal parts of the hidden story.
- **Story Progression:** Unlock new parts of the storyline by obtaining artifacts.
- **Adventure Gameplay:** Experience an interactive adventure while learning mathematics.

## Installation and Setup
1. Download or clone the repository.
2. Install the Java Development Kit (JDK).
3. Open the project using a Java-compatible IDE.
4. Make sure all required game assets are included.
5. Run the main Java class to start the game.
